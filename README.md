# Growfinix Real-Time Chat Support Widget

## Overview
A real-time AI-powered customer support platform built using React, Tailwind CSS, Node.js, Express.js and Socket.io.

## Features

- User Login System
- Real-Time Chat
- Socket.io Communication
- AI Auto Replies
- Typing Indicator
- Auto Scroll
- File Sharing
- Emoji Picker
- Chat History
- Download Chat
- Dark Mode
- Online / Offline Status
- Quick Replies
- Admin Dashboard
- User Management
- Live Chat Monitoring
- Analytics Dashboard
- Support Tickets
- File Upload Monitoring

## Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Socket.io Client
- React Router DOM
- Lucide React
- Recharts

Backend:
- Node.js
- Express.js
- Socket.io
